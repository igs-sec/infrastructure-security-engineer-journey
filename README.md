# Infrastructure Security Engineer Journey

A structured, hands-on learning journey from beginner level toward Infrastructure Security Engineering and, later, DevSecOps Engineering.

## Learning approach

- Start with IT and infrastructure fundamentals.
- Learn concepts before moving to advanced security topics.
- Practice in a home lab and document the results.
- Complete knowledge checks and practical assessments before advancing.
- Build a public portfolio while protecting personal data and secrets.
